# Update contract

Update Phase 1は新generationを固定し、決算、guidance、price、consensus、multiple、theme、competition、候補、corporate action、invalidation、comparability、evidenceの実差分だけを出す。初回観測を改善/悪化とは表現しない。Update Phase 2は全導出を再計算し、順位理由、PRIMARY/SECONDARY/CONDITIONAL/WATCH/EXCLUDED/NO_SELECTION変更、旧handoff失効、新handoffをimmutable historyとして生成する。
